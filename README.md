# Diversity Nexus Internship Assignments

This repository contains the Python assignments completed as part of the AI & ML Mastery Program – 60-Day Accelerated Plan. The focus is on building a strong foundation in Python programming, which is essential for learning Artificial Intelligence, Machine Learning, and Data Science concepts.

## Overview

The goal of this repository is to:
- strengthen Python fundamentals
- practice problem solving through coding exercises
- understand real-world logic building and debugging
- learn how to write clean, readable, and tested code
- prepare for advanced AI and ML topics using a structured learning path

## Learning Approach

The learning method followed in this repository is:

1. Understand the concept clearly.
2. Predict the output before running the code.
3. Write the program manually.
4. Test the program with valid and edge-case inputs.
5. Document the input, processing, and output.
6. Identify errors and fix them with understanding.
7. Reflect on what was learned from the exercise.

This approach helps build both coding confidence and logical thinking.

The program follows a structured 60-day plan designed to help learners move from basic Python to AI/ML readiness.

| Day | Week | Topic | Focus |
|-----|------|-------|-------|
| 1-5 | Week 1 | Python Basics | Variables, input/output, data types |
| 6-10 | Week 2 | Python Basics + Practice | Operators, strings, control flow |
| 11-15 | Week 3 | Data Handling | Lists, tuples, sets, dictionaries |
| 16-20 | Week 4 | Control Flow | Conditions, loops, logic building |
| 21-25 | Week 5 | Functions & Modules | Reusability and structured coding |
| 26-30 | Week 6 | Intermediate Python | Problem solving and mini projects |
| 31-35 | Week 7 | Data & ML Foundations | Data processing, analysis basics |
| 36-40 | Week 8 | ML Fundamentals | Models, evaluation, feature understanding |
| 41-45 | Week 9 | Applied ML | Projects and practical implementation |
| 46-50 | Week 10 | AI/ML Practice | Mini case studies and model workflows |
| 51-60 | Week 11-12 | Final Capstone | Full project development and review |
